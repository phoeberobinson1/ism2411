2. Changing How You Approach Edits

Using Git encourages a trial-and-error workflow where you can freely experiment because you always have a reliable safety net to roll back changes if something breaks. Instead of saving messy, ad-hoc backup copies (like script_final_v2.py), you make frequent, atomic commits whenever a specific feature works. Compared to before this module, I would test small pieces of code incrementally and commit working milestones rather than waiting until the entire project is finished.

4. Custom .gitignore Addition
